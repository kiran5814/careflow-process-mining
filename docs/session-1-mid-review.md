# CareFlow - Session 1 Mid-Review Notes

## Project Goal
Analyse healthcare process workflows to understand activity sequences, locate delays, and support data-driven improvements.

## Problem Being Addressed
Hospital workflows can involve multiple departments and activities. Process analysis can help reveal repeated steps, waiting times, and bottlenecks.

## Planned Analysis Steps
1. Understand the process and its business requirements.
2. Inspect the available event-log data.
3. Clean and validate the data.
4. Analyse process paths and activity durations.
5. Identify potential bottlenecks.
6. Present supported findings in a dashboard.

## Technical Components
- Python and Pandas: data preparation and analysis.
- PM4Py: process-mining techniques.
- dbt: structured data transformation, where configured.
- Dashboard: visual presentation of analytical results.
- Simulator: experimentation with simulated workflows, where implemented.
