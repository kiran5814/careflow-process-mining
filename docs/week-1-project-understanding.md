# Week 1 - CareFlow Project Understanding

## Project Overview
CareFlow is a healthcare process-mining project intended to help analyse hospital workflows and identify delays, bottlenecks, and opportunities for improvement.

## Problem Statement
Hospital processes such as patient registration, appointment handling, consultations, and discharge can experience delays. Analysing the sequence and timing of activities can help identify where improvements may be needed.

## Project Objectives
- Understand the hospital workflow and its activities.
- Identify the data needed to analyse process performance.
- Explore process-mining methods for finding bottlenecks.
- Plan how analytical findings can be presented in a dashboard.

## Initial Technical Plan
- Python for data processing.
- Pandas for data preparation and analysis.
- PM4Py for process-mining analysis.
- A dashboard for presenting process insights.
